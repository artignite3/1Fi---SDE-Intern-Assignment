# Progressive Web App Icons (public/icons/)

This directory contains the application launcher icons utilized by Web App Manifest (public/manifest.json), Apple touch icons, and browser favicons.

---

## Icon Specifications

| File | Size | Purpose | Platform |
| :--- | :--- | :--- | :--- |
| icon-192.svg | 192 × 192 px | Android Home Screen launcher icon / Chrome taskbar | Android, Chrome, Edge |
| icon-512.svg | 512 × 512 px | Android splash screen & desktop app installation | Android, Windows, macOS |

---

## Design Attributes

- **Background**: #5C24EB (Official 1Fi Brand Purple)
- **Foreground**: Modern white geometric "1Fi" typography with curved credit line motif
- **Maskable**: Conforms to W3C safe-zone standards for circular and rounded rectangle adaptive masks
