# Stores API Endpoint (src/app/api/stores/)

Provides a REST API endpoint to query nearby physical partner stores supporting 1Fi QR pay and instant offline credit.

---

## Endpoint Details

- **Route**: GET /api/stores
- **Query Parameters**:
  - city *(optional)*: Filter by city (e.g. Bangalore, Mumbai, Delhi).
  - query *(optional)*: Filter by store name or brand.
