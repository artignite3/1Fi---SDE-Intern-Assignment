# Profile & Action Modals Module (`src/components/profile`)

This directory houses user profile details, KYC status badges, and interactive modals triggered across the application.

---

## 📦 Components & Modals

### 1. `ProfileView.tsx`
- User avatar, verified phone number, pending/approved KYC indicators.
- Quick action list for Profile Details, Purchases, Pledge History, Invite Friends, Support & FAQs, Privacy Policy, Terms, and Log Out.

### 2. `SupportFAQModal.tsx`
- Expandable accordion covering key questions about 1Fi, Mutual Fund liens, RBI-approved lending partners, CAMS/KFintech lien mechanics, and returns.

### 3. `ReferAndEarnModal.tsx`
- Referral link generator with 1-tap clipboard copying and bonus reward milestone cards.

### 4. `PurchasesModal.tsx`
- Displays historical orders sanctioned through the 1Fi Marketplace, voucher codes for redemption, and active EMI repayment schedules.
