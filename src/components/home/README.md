# Home View (`src/components/home`)

This component renders the primary dashboard matching the 1Fi application walkthrough screenshots.

---

## 📦 Components

### `HomeView.tsx`
- **Credit Limit Card**: Displays available credit line (`₹2,50,000`), connected MF portfolio value (`₹4,85,000`), and quick limit unlock simulator button.
- **Quick Action Grid**: 1-tap shortcuts for "Check Limit", "Browse Shop", "Repay Early", and "Invite Friends".
- **Offer Carousel**: Featured merchant promotions (MakeMyTrip, Apple, Dyson).
- **Why Pay With 1Fi**: Value proposition cards (0% interest, no tax/exit load, quickest approvals).
- **FAQ Accordion Teaser**: Direct link to the FAQs modal.
